# 자산의 다음

금융자산과 보유 부동산을 합산하고 부동산 구매 가능 금액을 계산하는 한국어 웹앱입니다.

## 실행

별도 설치나 빌드 없이 `dist/index.html`을 브라우저로 열거나 정적 서버로 제공합니다.

```sh
python3 -m http.server 8000 --directory dist
```

## 기능

- 현금, 퇴직연금, 주식, 금, USD·JPY·EUR 합산
- 부동산 주소, 평가 기준일, 지분, 담보대출·반환보증금, 매각비용 반영
- 총자산·순자산·매수 자기자금 구분
- 주택·비주택별 LTV, 별도 대출 한도, 취득비용 시뮬레이션
- 자동 저장·저장 시각, 이름별 자산 기록(최대 100개), 이전 입력 복구
- 현재 입력 및 전체 기록 JSON 백업·복원 (기존 백업 호환)
- 네이버 증권의 최신 매매기준율 및 국내 금 기준가 조회

## 계산

자기자금 A, 대출비율 L, 취득 부대비용률 C일 때 매수가격은 `A / (1 - L + C)`입니다.
대출한도 B가 있으면 위 결과와 `(A + B) / (1 + C)` 중 작은 값을 사용합니다.
JPY 환율은 100엔당 원화 기준입니다. 금은 1돈당 원화 단가를 입력합니다.

## 현재 제한

공시가격 자동 조회는 미연결입니다. 주소·필지 및 동·호수 매칭 연동은 후속 작업입니다.

네이버 시세 조회는 Vercel의 `/api/market` 함수에서 수행합니다. 정적 파일만 열면 자동 조회를 사용할 수 없습니다. Vercel에서 프로젝트 전체를 배포하세요.
환율은 하나은행 고시값이며 엔화는 100엔 기준입니다. 국내 금은 신한은행 원/g 기준가에 3.75를 곱해 원/돈으로 평가합니다. 실물 순금 매입·매도 가격, 부가세·수수료와 다릅니다.
한국시간 기준 당일 자료인지 표시하며 휴장·미고시일에는 실제 고시일을 유지합니다. 일부 조회 실패 시 해당 항목 기존 단가를 유지합니다. 네이버 데이터 경로·형식 변경 또는 접근 제한 시 자동 조회가 실패할 수 있습니다.
공시가격은 시장 시세와 다릅니다. 대출 비율은 사용자 가정이며 실제 대출 가능 여부는 금융기관 심사로 결정됩니다.

## 데이터

개인 입력은 사용 중인 브라우저에 저장되며 이 저장소에 포함되지 않습니다. 백업 JSON에는 개인 자산 정보가 포함되므로 저장소에 커밋하지 마세요.

## 파일

- `dist/index.html`: 화면
- `dist/style.css`: 반응형 스타일
- `dist/app.js`: 입력·저장·계산
- `api/market.js`: 네이버 환율·금 조회 서버 함수
- `vercel.json`: Vercel 배포 설정
- `.openai/hosting.json`: 기존 Sites 배포 설정
